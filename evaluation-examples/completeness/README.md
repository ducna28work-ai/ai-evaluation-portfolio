# Completeness Evaluation Example

## Overview

This example demonstrates how to evaluate whether an AI response covers all important requirements of a user's request.

The examples are synthetic and created for portfolio demonstration purposes.

---

## Example 1 — Mostly Complete

### User Request

> Explain three benefits of internal linking for SEO and give one practical example for each benefit.

### AI Response

> Internal linking provides several SEO benefits:
>
> 1. **Improves website navigation:** Internal links help users move between related pages.
>
>    Example: A travel website can link from a Vietnam travel guide to a related Hanoi tour page.
>
> 2. **Helps search engines discover pages:** Internal links create pathways that crawlers can follow to find additional content.
>
>    Example: A category page can link to individual articles within that category.
>
> 3. **Helps distribute internal authority:** Internal links can help connect important pages with supporting content.
>
> Internal linking should be considered together with other SEO activities such as content optimization and technical SEO.

---

## Evaluation

### User Objective

The user wants:

- Three benefits of internal linking for SEO.
- One practical example for each benefit.

### Requirement Mapping

| Requirement | Status | Evidence |
|---|---|---|
| Benefit 1 | Fully Addressed | Website navigation |
| Example for Benefit 1 | Fully Addressed | Travel guide → Hanoi tour |
| Benefit 2 | Fully Addressed | Search engine discovery |
| Example for Benefit 2 | Fully Addressed | Category page → articles |
| Benefit 3 | Fully Addressed | Internal authority |
| Example for Benefit 3 | Not Addressed | No specific example provided |

### Missing Component

The response does not provide a practical example for the third benefit.

### Overall Judgment

**Mostly Complete**

### Rationale

The response covers all three requested benefits and provides examples for the first two. However, it does not provide the requested example for the third benefit. The main task is largely fulfilled, but one important component is missing.

### Completeness Issue

**Missing Requested Component**

### Severity

**Minor**

## Example 2 — Partially Complete

### User Request

> Explain three benefits of internal linking for SEO and give one practical example for each benefit.

### AI Response

> Internal linking helps SEO by improving website navigation and helping search engines discover related pages.
>
> For example, a travel website can link from a destination guide to a related tour page.
>
> Internal links are also useful because they connect related content within a website.

---

## Evaluation

### User Objective

The user wants three benefits and one practical example for each benefit.

### Requirement Mapping

| Requirement | Status | Evidence |
|---|---|---|
| Benefit 1 | Fully Addressed | Website navigation |
| Example for Benefit 1 | Fully Addressed | Destination guide → tour page |
| Benefit 2 | Fully Addressed | Search engine discovery |
| Example for Benefit 2 | Partially Addressed | The example may relate to internal linking but is not clearly tied to search engine discovery |
| Benefit 3 | Partially Addressed | Related content is mentioned but not clearly explained as a distinct benefit |
| Example for Benefit 3 | Not Addressed | No example |

### Missing Components

The response does not clearly provide:

- Three distinct benefits.
- One clear example for each benefit.

### Overall Judgment

**Partially Complete**

### Rationale

The response provides useful information about internal linking and addresses some of the requested benefits. However, it does not clearly provide three distinct benefits or an example for each one. Several requirements therefore remain only partially addressed or missing.

### Completeness Issues

- Partial Topic Coverage
- Missing Requested Items
- Missing Examples

### Severity

**Major**

## Example 3 — Complete

### User Request

> Give me three practical steps for improving internal linking on a website.

### AI Response

> 1. **Identify important pages:** Find pages that are important to the business and prioritize them for internal links.
>
> 2. **Create contextual links:** Add links from relevant articles or pages to other related pages where the link provides useful context.
>
> 3. **Review and update existing links:** Regularly check important pages for broken, outdated, or missing internal links.

---

## Evaluation

### Requirement Mapping

| Requirement | Status |
|---|---|
| Step 1 | Fully Addressed |
| Step 2 | Fully Addressed |
| Step 3 | Fully Addressed |

### Overall Judgment

**Complete**

### Rationale

The user requested three practical steps. The response provides three distinct steps, each directly related to improving internal linking. No important requested component is missing.

---

## Key Evaluation Takeaway

Completeness should be evaluated by mapping the user's requirements against the information actually provided in the response.

A response can contain accurate and relevant information but still be incomplete when important requested components are missing.

The evaluator should therefore follow:

**Task Requirements → Requirement Mapping → Covered Components → Missing Components → Importance → Overall Judgment**

The focus should be on whether the response provides enough information to fulfill the user's intended outcome, rather than simply measuring response length.
