# Pairwise AI Response Evaluation

## Overview

This project demonstrates a structured pairwise comparison process for evaluating two AI responses to the same user request.

Instead of evaluating each response independently and stopping at an overall score, pairwise evaluation compares the responses against the same criteria and records evidence for the differences.

The evaluation focuses on:

- Instruction Following
- Factuality & Accuracy
- Relevance
- Completeness
- Response Quality
- Safety & Policy Compliance

The examples are synthetic and created for portfolio demonstration purposes.

---

## Pairwise Evaluation Workflow

**User Task → Response A & Response B → Shared Criteria → Evidence → Dimension Comparison → Preference / Tie → Rationale → Quality Check**

---

# 1. Synthetic Evaluation Task

### User Request

> Explain three practical benefits of internal linking for SEO. Give one example for each benefit. Keep the answer concise and suitable for someone who is new to SEO.

---

# 2. Response A

> Internal linking can help SEO in several ways:
>
> 1. **Better navigation:** Internal links help users move between related pages. For example, a travel website can link from a Vietnam travel guide to a related Hanoi tour page.
>
> 2. **Page discovery:** Internal links give search engine crawlers paths to discover other pages. For example, a category page can link to articles within that category.
>
> 3. **Stronger page relationships:** Internal links connect pages covering related topics. For example, an article about Hanoi travel can link to another article about Hanoi attractions.
>
> Internal linking is one part of SEO, alongside backlinks, technical SEO, content quality, and keyword research.

---

# 3. Response B

> Internal links are links that connect one page on your website to another page on the same website.
>
> Three practical benefits are:
>
> 1. **Better navigation:** Users can move easily between related pages.
>
>    Example: A Vietnam travel guide can link to a Hanoi tour page.
>
> 2. **Better page discovery:** Search engines can follow internal links to discover pages.
>
>    Example: A category page can link to individual articles.
>
> 3. **Clearer website structure:** Internal links help establish relationships between related pages.
>
>    Example: An article about Hanoi can link to a related article about Hanoi attractions.
>
> In practice, internal links should be added where they are useful and relevant to the reader.
